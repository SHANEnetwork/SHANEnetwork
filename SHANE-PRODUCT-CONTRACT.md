# SHANE: Non-negotiable product vision

## One-sentence contract
**The person describes the endeavor they imagine. SHANE designs, writes, builds, configures, and refines the actual website and its supported capabilities; the person guides the vision and approves important decisions.**

## The primary experience
1. **Vision:** Invite a free-form description, including uncertain and unconventional ideas. Do not demand technical selections.
2. **Interpretation:** SHANE identifies audience, purpose, tone, pages, visuals, content, and potentially useful capabilities. Distinguish confirmed requirements from possibilities and questions.
3. **Creation:** SHANE produces a visually rich, responsive, editable, working website draft and configures supported capabilities itself. Show the real preview.
4. **Conversation:** The person says what to change in ordinary language. SHANE updates the draft, preserves unaffected work, and explains material changes.
5. **Publication:** Save and publish only with explicit user action. Preserve project ownership, security, and rollback/undo paths.

## Product rules
- **No configuration homework:** Do not make the person choose a template, layout, colors, page count, modules, databases, or integrations before SHANE can begin. Advanced editing may exist as an optional escape hatch.
- **AI does the work:** The primary action is to describe a vision, then see SHANE build it. Do not substitute a checklist, generic proposal, mock button, or an unimplemented feature for a working website.
- **Rich, distinct design:** Aim for warm, welcoming, expressive, professional websites with appropriate imagery, hierarchy, typography, depth, and responsive layout. Avoid a one-size-fits-all corporate/admin appearance.
- **Function follows purpose:** A festival may need event details, volunteer coordination, registrations, and updates. A club may need membership and discussions. A shop may need catalog and checkout. SHANE should infer needs and provision only capabilities actually supported by its system.
- **Honest capabilities:** A link to a shared SHANE service is not an automatically created, endeavor-specific forum or registration system. Never claim it is.
- **Respect uncertainty:** A possible farmers market is not a confirmed central feature. Ask concise questions only when the answer is essential or high-stakes; otherwise make revisable choices.
- **Keep continuity:** Preserve existing decisions, writing, styling, data, and working features across revisions. Never overwrite SHONnetwork while working on SHANEnetwork.
- **Protect users:** Avoid inventing real-world facts, fake testimonials, fabricated dates or prices, or publishing without consent. Keep private member information protected.

## Definition of a meaningful milestone
A real person can describe an idea, receive an attractive editable website draft, request a change conversationally, see it reflected in the live preview, save the project, reload it without losing choices, and publish deliberately. Each promised module must be demonstrably functional and associated with the correct endeavor.

## Implementation status note
This document is the product contract, **not a claim that all features are implemented**. Current AI generation depends on account access and a configured provider; network links are not yet automatically provisioned private community services. Prioritize closing those gaps over adding more setup controls.
